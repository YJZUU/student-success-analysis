# student-success-analysis
2024 경진대회 - 학생 성공 설문

## 📊 학생 성공 설문 분석
전주대학교 빅데이터 분석 경진대회 | 장려상 (3위) | 2024

전주대학교 학생 성공 설문 전 문항을 검토해 학년별로 성공·만족도에
직접 영향을 미치는 핵심 변수를 파악하고 맞춤 지원 방향을 도출한 프로젝트입니다.

## 🔍 핵심 발견

- 학교생활 만족도 — 교우관계 상관계수 **r = 0.59**
- 카이제곱 검정 유의수준 **p = 0.021~0.026**
- 1·2학년 핵심 변수 — 전공 적응·정체성 확립
- 3·4학년 핵심 변수 — 진로·취업 실무 역량
- 2·3학년 성공 인식 저하 원인 — 전공 선택 불확실성으로 특정

## 📊 분석 흐름

1. **문항 선별** — 전 문항 개별 검토 후 팀원 간 교차 검토로 영향 변수 확정
2. **카이제곱 검정** — 학년별·단과별 유의미한 차이 검증 (SPSS + Python)
3. **상관관계 분석** — 주요 변수 간 상관관계 매트릭스 산출
4. **학년별 경로 실증** — 학년별 성공 인식 경로가 다르게 작동함을 확인
5. **정책 제안** — 전북 LISG 산학 연계 강화 방안 제안

## 💡 제안 방안

- 저학년 — 전공 적응·정체성 확립 중심 지원 프로그램
- 고학년 — 진로·취업 실무 역량 연계 프로그램
- 2·3학년 전공 선택 불확실성 해소를 위한 산학 연계 강화 (전북 LISG 정책 연계)
